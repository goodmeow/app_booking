# Phase 10B Usability Test Protocol

Status: ready to run. External evidence still required before marking the
`TODO.md` five first-time user task complete.

## Participant target

- 5 first-time users who have not used this reconstructed scheduler.
- Mix at least 2 non-admin employees and 1 admin/operator.
- Test on one desktop viewport and one phone-width viewport.

## Tasks

1. Create a normal room meeting from `Jadwal Saya`.
2. Find a room schedule from `Jadwal Ruangan`.
3. Create one continuous multi-day booking.
4. Create a recurring meeting and review occurrence/conflict feedback.
5. Edit one occurrence, then cancel one meeting.
6. Admin only: add a user, add a room, and find Access Cards from mobile tabs.

## Pass criteria

- 4 of 5 users complete create/edit/cancel without facilitator intervention.
- 4 of 5 users can distinguish multi-day booking from recurring schedule.
- 4 of 5 users can recover from a load error using visible retry.
- No user reaches a dead-end on an unknown route.
- Admin tester finds Users, Rooms, and Access Cards without horizontal navbar scroll.
