# Agent notes (app_booking)

## Human-readable code (wajib)

Semua kode di repo ini harus bisa dibaca manusia:

- Nama variabel/fungsi jelas; hindari singkatan yang tidak perlu.
- SQL ditulis multi-baris dan rapi, tidak menempel satu baris panjang.
- Satu baris satu pernyataan; hindari ekspresi bersarang yang sulit dibaca.
- Komentar hanya untuk alasan/keputusan yang tidak terlihat dari kode.
- Ikuti gaya file sekitarnya (import, urutan, penamaan, format).
- Tidak ada kode termampatkan atau trik pintar; utamakan kejelasan.

## Revamp Ant Design 5

- Rencana, cleanup inventory, dan log ada di `docs/revamp-antd5.md`.
- Sebelum mulai, baca status dan log terakhir di dokumen itu.
- Setiap perubahan wajib menambah baris di bagian **Log perubahan**.
- Catat minimal: tanggal, fase, perubahan, file utama, dan verifikasi.
- Jangan hapus baris log lama; tambahkan baris baru.

Pelengkap `docs/CMS.md` (peta halaman web admin).
